MULTI-AGENT LLM · OPEN SOURCE

MARS: Multi-Agent Research System

A research assistant made of 11 LLM agents in a LangGraph state machine. It writes reports where every citation points to a retrieved source chunk. A QC agent scores each draft and sends weak ones back for another search, and the retrieval tools run through an MCP server.

Problem Research agents hallucinate sources and stop at the first draft, with no grounding and no self-correction.
Approach ReAct researcher (MCP tools) → structured analyst → 3 parallel critics → synthesizer → QC gate that retries with a new search strategy when the score is too low.
Outcome 13 of 15 test runs passed QC on the first try (preliminary). No broken citation tags, which checks that the source exists, not that it supports the claim.
Researcher (MCP) → Analyst → Parallel Critics ×3 → Synthesizer → QC Gate (retry)
13/15 QC first-pass 0 broken citation tags 11 agents
LangGraph Gemini 2.5 Flash PydanticAI MCP Streamlit

EDGE AI · VOICE + VISION

VEST: Voice Assistant on a Jetson

An offline-first voice and vision assistant for a Jetson worn on a vest. You ask a question out loud, it finds the matching procedure out of 100 SOPs, looks at the camera frame, and speaks the answer.

Problem A field assistant that has to work without a reliable connection to a cloud API.
Approach Vosk speech-to-text, CLIP + ChromaDB retrieval over the SOPs, Qwen3-VL through Ollama for the camera frame, Piper for speech. If the camera, model, battery or temperature fails, it says so out loud and drops to a simpler mode.
Outcome About 4.1 s from spoken question to spoken answer on an AGX Orin 64GB with a warm model, and about 13.8 s on an Orin NX 16GB with a smaller model. Both are my own measurements.
Qwen3-VL Ollama CLIP · ChromaDB NVIDIA Jetson Vosk · Piper
NEURO-SYMBOLIC AI

Bio-Oracle

A neuro-symbolic agent for drug-discovery screening. Cellpose segments the cells, then a PydanticAI agent (Gemini) answers questions by calling statistical tools over the extracted features, so each answer can be traced.

Approach Cellpose segmentation → 30+ morphological features → robust Z-score normalization → PydanticAI + Gemini agent.
Outcome 98% outlier precision flagging Taxol-induced actin changes on the BBBC021 dataset. Runs in Docker.
